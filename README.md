# SwiftUI Basic Components Demo

This is a simple iOS application built using **SwiftUI** that demonstrates commonly used UI components and layouts.

## 📱 Features

- ✅ TextField for user input (Name & Mobile Number)
- ✅ Buttons with custom actions
- ✅ Toggle switch to enable/disable a feature
- ✅ Static List view with fruits
- ✅ Navigation to a Detail View using `NavigationLink`
- ✅ ScrollView and VStack layout for smooth scrolling

## 📂 Structure

- `ContentView.swift` – Main screen containing all basic components
- `DetailView.swift` – A simple view navigated to from the main screen

## Getting Started
Follow these steps to set up and run the project on your local machine.

### Requirements

- macOS with Xcode installed (Xcode 14 or newer recommended)
- Swift 5.7+
- iOS 15.0+ deployment target
